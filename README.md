# Website Builder Agent

A Claude Code subagent, [`.claude/agents/website-builder.md`](./.claude/agents/website-builder.md), and the skill it
works through, [`.claude/skills/website-build/`](./.claude/skills/website-build/SKILL.md). Together they build a new
multi-language marketing website from brief to go-live:

- architecture and build pipeline, with backups at every step;
- design system, typography and real-screen phone mockups;
- translations;
- SEO and GEO (being cited by AI search);
- performance, consent and analytics, and legal pages;
- QA across devices, widths, modes and social in-app browsers;
- a reviewed deploy.

**This is a generic template**, extracted from a real production build: a five-language marketing site for a mobile
app, built and launched with Claude Code in about six weeks, then hardened after go-live. It has been anonymised:
every company name, person, URL, ID and business figure has been removed. What is left are the rules, each with
the reason it exists. Most of them come from something that actually broke.

## Use it

1. Copy `.claude/agents/website-builder.md` and `.claude/skills/website-build/` into your project's `.claude/`.
2. Optional, but recommended: merge `examples/settings.hooks.json` into `.claude/settings.json`, so every file edit is versioned into `.versions/`. Add `.versions/` to `.gitignore`.
3. Ask Claude Code: *"Use the website-builder agent to build a site for ..."*. It asks for the brief first.

## The rules that saved the most time

- One source of truth. Language versions are generated by exact-text-match builders, and line breaks are done at runtime, so translations still match.
- A page that renders proves nothing. Syntax-check every inline script, then measure the full page × width matrix. A spot check once passed a fix that failed in 18 of 24 combinations.
- Every round of feedback becomes a scripted, idempotent build pass that fails if its target text disappears.
- Facts live in one list. The same number written three ways on three pages is a trust problem and a GEO problem.
- Test CSP and consent where your traffic actually lands. A strict `connect-src` silently blocked the Meta pixel's click-ID handoff inside the Android Facebook and Instagram in-app browsers.
- One build at a time, under a lock that checks its owner. Check free memory before a full build: parallel sessions starving the machine killed builds halfway.
