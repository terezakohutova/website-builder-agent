Notizen, die Sie wiederfinden.

Lumen Notes ist eine erfundene App. Sie zeigt, was das QA-Werkzeug in diesem Repository prüft: Überlauf bei jeder Breite, defekte Bilder, Konsolenfehler, die Syntax von Inline-Skripten und Sprungmarken.

So funktioniert es

Funktionen

  • Schnell notiert

    Eine Notiz mit zwei Fingertipps. Lange Wörter wie Notizbuchverwaltungsfunktion brechen trotzdem um.

  • Suche

    Jede Notiz über ein Wort finden, an das Sie sich erinnern.

  • Offline

    Alles funktioniert ohne Verbindung und wird später synchronisiert.

So geht's

  1. 1 App installieren.
  2. 2 Erste Notiz schreiben.
  3. 3 Eine Woche später danach suchen.

FAQ

Gibt es Lumen Notes wirklich?

Nein. Es ist ein erfundenes Produkt für eine Testseite.

Wozu diese Seite?

Damit die QA-Skripte ein kleines, ehrliches Ziel haben und der Bericht in qa-report/ reproduzierbar ist.
