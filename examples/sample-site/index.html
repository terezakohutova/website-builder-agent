Lumen Notes is an invented app used to show what the QA harness in this repository checks: overflow at every width, broken images, console errors, inline script syntax and same-page anchors.

Features

  • Quick capture

    Write a note in two taps. Long German compounds like Notizbuchverwaltungsfunktion still wrap.

  • Search

    Find any note by a word you remember, in any language you wrote it in.

  • Offline

    Everything works without a connection and syncs when you are back online.
